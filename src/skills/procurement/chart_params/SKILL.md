# 图表参数速查手册

## 常用图表类型

### 1. 柱状图 (bar)
**适用场景**：类别对比、数量对比
**参数**：
```python
{
    "type": "bar",
    "title": "供应商价格对比",
    "x_label": "供应商",
    "y_label": "价格（元）",
    "data": {"博世": 280, "大陆": 320, "采埃孚": 450}
}
```

### 2. 折线图 (line)
**适用场景**：时间趋势、变化趋势
**参数**：
```python
{
    "type": "line",
    "title": "价格趋势图",
    "x_label": "时间",
    "y_label": "价格",
    "data": {"2024-01": 280, "2024-02": 290, "2024-03": 285}
}
```

### 3. 饼图 (pie)
**适用场景**：占比分析、分布分析
**参数**：
```python
{
    "type": "pie",
    "title": "物料库存分布",
    "data": {"充足": 5, "预警": 2, "短缺": 1}
}
```

### 4. 散点图 (scatter)
**适用场景**：相关性分析、分布分析
**参数**：
```python
{
    "type": "scatter",
    "title": "价格与质量关系",
    "x_label": "价格",
    "y_label": "质量评分",
    "data": [[280, 4.8], [320, 4.6], [450, 4.7]]
}
```

### 5. 面积图 (area)
**适用场景**：累计趋势、堆叠分析
**参数**：
```python
{
    "type": "area",
    "title": "采购金额累计趋势",
    "x_label": "月份",
    "y_label": "金额",
    "data": {"1月": 10000, "2月": 25000, "3月": 40000}
}
```

## 图表生成工具

使用 `chart_generator` 工具生成图表，传入上述参数即可。

生成的图表会保存到 `/analysis/charts/` 目录下。

## 选择建议

| 分析目的 | 推荐图表 |
|---------|---------|
| 类别对比 | 柱状图 |
| 时间趋势 | 折线图 |
| 占比分布 | 饼图 |
| 相关性 | 散点图 |
| 累计趋势 | 面积图 |
| 多维度对比 | 雷达图 |
| 流程分析 | 桑基图 |
| 地理分布 | 地图 |
