# 采购分析操作手册

## 概述

本技能指导 Agent 进行专业的采购数据分析，包括供应商对比、价格趋势、库存预警等。

## 分析流程

### 1. 明确分析目标
- 确定分析维度（供应商、物料、时间范围）
- 确定输出格式（报告、图表、数据表格）

### 2. 数据采集
使用以下 MCP 工具采集数据：
- `supplier_query` - 查询供应商列表
- `supplier_detail` - 获取供应商详情
- `part_query` - 查询物料信息
- `order_search_details` - 查询历史订单
- `inventory_warning` - 查询库存预警

### 3. 数据处理
- 数据清洗和格式化
- 计算关键指标（均价、涨幅、库存周转率等）
- 可以使用 Python 脚本进行复杂计算

### 4. 生成报告
报告结构：
1. 分析摘要
2. 数据表格
3. 图表展示
4. 分析结论
5. 采购建议

## 分析模板

### 供应商对比分析
```
# 供应商对比分析报告

## 分析对象
- 物料：{material_name}
- 对比供应商：{suppliers}

## 价格对比
| 供应商 | 单价 | 评级 | 交货期 | 最小起订量 |
|--------|------|------|--------|-----------|
| ...    | ...  | ...  | ...    | ...       |

## 结论与建议
1. ...
2. ...
```

### 价格趋势分析
```
# 价格趋势分析报告

## 分析范围
- 物料：{material_name}
- 时间范围：{start_date} ~ {end_date}

## 价格走势
（图表：折线图展示价格变化）

## 关键发现
1. 最高价：{max_price}（{date}）
2. 最低价：{min_price}（{date}）
3. 平均价：{avg_price}
4. 涨跌幅：{change_rate}%

## 采购建议
...
```

## 注意事项
1. 数据来源要明确标注
2. 价格分析要考虑通货膨胀因素
3. 供应商评级要综合考虑价格、质量、交货期
4. 报告要给出可执行的建议，而不仅仅是数据罗列
